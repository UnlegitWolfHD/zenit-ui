### `src/app/server/server-page.html`

changed, converted: icon 6, button 7, tooltip 3, spinner 1, chip 1

| Line:Col | Rule | Kind | Code | Reason | Suggested fix |
| --- | --- | --- | --- | --- | --- |
| 7:7 | icon | manual | icon-in-field | The icon is projected into a mat-form-field through matPrefix. | Migrate the field to z-field and use the icon of z-input-group. |
| 9:7 | button | review | button-no-name | The icon-only button has no accessible name: z-icon is aria-hidden and a tooltip is a description, not a label. | Add an aria-label, usually the tooltip text: aria-label="Feld leeren". |
| 40:5 | button | review | button-type | The button has no type attribute, so inside a <form> it submits. It was not added, because that would change what the button does. | Add type="button", or type="submit" where the button is meant to submit. |
| 45:9 | icon | review | icon-in-menu-item | The icon sits in a mat-menu-item, which projects <mat-icon> into its own slot. | When the menu is migrated the icon becomes the "icon" input of button[zMenuItem]. |
| 51:5 | spinner | review | spinner-no-label | The spinner has no accessible label; without one z-spinner is decorative and aria-hidden. | Add label="Wird geladen" (or what is loading) for a standalone loading state; leave it out only where text next to it says the same. A list that loads shows z-skeleton rows instead of a spinner. |
| 66:15 | chip | review | chip-status | The chip became a neutral z-badge. | Where it shows a state, set status="success\|warning\|danger\|info" and dot, and keep the state as a word. |
| 74:11 | button | review | button-no-name | The icon-only button has no accessible name: z-icon is aria-hidden and a tooltip is a description, not a label. | Add an aria-label, usually the tooltip text: [attr.aria-label]="'Server ' + server.name + ' löschen'". |
| 74:11 | button | review | button-warn | color="warn" was dropped: zenit-ui has no colour input, colour must come from the context. | Candidate for zBtn="danger": use it only where the action destroys something, and confirm it with a dialog. |
| 74:11 | tooltip | review | tooltip-disabled-merged | [matTooltipDisabled]="!server.deletable" was merged into the text: an empty zTooltip shows nothing. | Check the expression. |
| 100:5 | spinner | manual | spinner-in-button | The spinner sits inside a <button> and was left alone: zBtn shows its own spinner. | Replace it with [loading] on the button: [loading]="saving", and remove the spinner and the label swap around it. loading also disables the button. |
| 103:3 | button | review | several-primaries | This template now has 2 buttons with zBtn="primary". The design system allows at most one primary per screen height. | Keep the one action the screen exists for as primary and make the others zBtn (secondary) or zBtn="ghost". |
