PageHeader eröffnet jede Seite im Kundenbereich: Titel links, Aktionen rechts.

## Du lieferst

Den Seitentitel in `heading-1`, der genauso heißt wie der Link in der Navigation. Optional eine Zeile mit dem wichtigsten Fakt der Seite. Höchstens zwei Buttons, einer davon primary.

## Regeln

- Die kleinen Überzeilen ("Verwaltung", "Konto", "Cloud", "Support") entfallen. Sie sagen nichts, was die Navigation nicht schon sagt.
- Titel und Navigation stimmen überein: heute heißt der Link "Gameserver" und die Seite "Game-Server", "Abrechnung" heißt "Finanzen".
- Der Gruß auf dem Dashboard ("Guten Tag, Name") wird zum Titel "Dashboard". Der Name steht schon am Avatar.
- Abstand zum Inhalt `space-6`. Unter 640px stehen die Aktionen unter dem Titel.
