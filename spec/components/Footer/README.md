Footer schließt jede Seite ab, öffentlich mit drei Spalten, im Kundenbereich nur mit der unteren Zeile.

## Du lieferst

Bis zu vier Linkgruppen mit je einem Wort als Überschrift. Rechtliche Links sind Pflicht auf jeder Seite, auch im Panel.

## Regeln

- Oben 1px `border`, Hintergrund `bg`. Kein Farbwechsel, kein Logo-Block, keine Wiederholung des Slogans.
- Links in `text-muted`, beim Hover `text`. Rot wird hier nicht benutzt.
- Im Kundenbereich nur `z-footer__base` mit Copyright links und den vier rechtlichen Links rechts. So ist es heute schon, das bleibt.
- "Alle Rechte vorbehalten" entfällt, das Copyright reicht.
- Discord ist ein Textlink, kein Marken-Icon.
