EmptyState füllt eine Liste, die noch keine Einträge hat.

## Du lieferst

Einen Titel, der den Zustand benennt, einen Satz, der weiterhilft, und einen secondary Button für den ersten Eintrag.

## Regeln

- Kein großes graues Icon. Der Text trägt den Zustand.
- Steht im PageHeader schon ein primary für dieselbe Aktion, ist der Button hier secondary. Heute zeigt Support "Neues Ticket" und "Ticket erstellen" beide in Rot.
- Eine leere Liste zeigt keine Pagination und keine Filter.
- "Verbrauchsdaten gerade nicht verfügbar" ist ein Fehler und bekommt einen Alert mit Grund.
- Unter leeren oder kurzen Listen bleibt die Seite nicht leer: Das Dashboard zeigt unter den Panels die Auslastung der laufenden Server.
