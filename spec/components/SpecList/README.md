SpecList zeigt Fakten als Begriff-Wert-Paare. Sie ersetzt Kennzahlen-Kacheln, Chip-Wolken und Feature-Karten auf öffentlichen Seiten.

## Du lieferst

Eine `dl` mit kurzen Begriffen und konkreten Werten. Technische Werte in `z-mono`, Zusätze in `small`.

## Regeln

- Ein Fakt steht auf einer Seite genau einmal. Heute nennt die Startseite DDoS-Schutz viermal und den Standort elfmal.
- Auf der Startseite ersetzt eine SpecList die Trust-Leiste, die sechs Statistik-Kacheln und die 16 Chips. Auf /hardware ersetzt je Node eine SpecList die Karte mit Versal-Labels.
- Keine Icons, keine Karten. 1px-Linien in `border` zwischen den Zeilen.
- Die Werte im Beispiel stammen von /hardware (Node Normal).
- Unter 480px steht der Wert unter dem Begriff.
