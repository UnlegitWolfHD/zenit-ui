Alert ist ein Hinweis im Seitenfluss, der eine Ursache nennt und eine Handlung anbietet.

## Du lieferst

Ein Icon, einen Titel als ganzen Satz, optional einen zweiten Satz und höchstens einen Button (secondary, `z-btn--sm`).

## Varianten

`z-alert--info` für Hinweise, `--success` nach abgeschlossenen Vorgängen, `--warning` wenn der Kunde bald handeln sollte, `--danger` wenn etwas fehlgeschlagen ist. Ohne Modifier neutral.

## Regeln

- Fehlertexte sagen, was passiert ist und was der Kunde tun kann. Keine Entschuldigungen, kein "Ups".
- Die Farbe liegt nur auf Fläche und Icon. Kein Randstreifen links, kein Rahmen.
- Mobil bricht der Button unter den Text um. Heute überlappen im Hinweis "Fehlt dein Lieblingsspiel?" Text und Link bei 375px.
- Flüchtige Rückmeldungen ("Gespeichert") sind Toasts, keine Alerts.
- Höchstens ein Alert pro Seite über dem Inhalt. Mehrere Meldungen werden zusammengefasst.
